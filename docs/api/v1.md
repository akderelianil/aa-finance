# aa-finance named-operation API, version 1

_Generated from [`api/v1/api.json`](../../api/v1/api.json) by `npm run api:docs`. Do not edit by hand: change the contract first (ADR-0023)._

The authority for the boundary between the core and the UI, the command line and plugins (ADR-0023). Change this file first, then the code. Additive changes keep the version; removing or renaming a field or changing a type is breaking.

Every operation can also return: `invalid_input`, `unknown_operation`, `database`, `internal`, `invalid_body`, `foreign_database`, `newer_database`.

## Operations

### `open_book`

Opens a new book: its base currency and its settings, written together. A book is opened once.

- Input: { base_code: `string`, base_scale: `integer` }
- Output: `DocRef`
- Errors: `book_already_open`, `name_empty`, `commodity_scale_invalid`

### `settings`

Reads the settings of the book.

- Input: `Empty`
- Output: `SettingsView`
- Errors: `missing_reference`

### `set_base_currency`

Changes the base currency. Refused once any entry exists.

- Input: { commodity: `DocId` }
- Output: `DocRef`
- Errors: `base_currency_locked`, `missing_reference`, `conflict`

### `create_commodity`

Adds a currency or commodity with its scale.

- Input: { code: `string`, scale: `integer` }
- Output: `DocRef`
- Errors: `commodity_code_taken`, `commodity_scale_invalid`, `name_empty`

### `create_account`

Adds an account.

- Input: `AccountInput`
- Output: `DocRef`
- Errors: `name_empty`, `account_name_taken`, `account_parent_archived`, `account_parent_kind_mismatch`, `account_parent_cycle`, `missing_reference`

### `rename_account`

Renames an account. Locked accounts are refused.

- Input: { account: `DocId`, name: `string` }
- Output: `DocRef`
- Errors: `account_locked`, `name_empty`, `account_name_taken`, `missing_reference`, `conflict`

### `set_account_archived`

Archives or restores an account. Locked accounts are refused.

- Input: { account: `DocId`, archived: `boolean` }
- Output: `DocRef`
- Errors: `account_locked`, `missing_reference`, `conflict`

### `post_entry`

Posts a balanced entry (at least two lines).

- Input: `EntryInput`
- Output: `DocRef`
- Errors: `entry_too_few_lines`, `entry_unbalanced`, `line_empty`, `line_base_sign`, `line_commodity_mismatch`, `account_archived`, `amount_invalid`, `amount_too_precise`, `amount_out_of_range`, `rate_invalid`, `rate_missing`, `rate_base_conflict`, `date_invalid`, `missing_reference`

### `edit_entry`

Replaces an entry with a new version. A deleted entry is refused; undo first.

- Input: { entry: `DocId`, input: `EntryInput` }
- Output: `DocRef`
- Errors: `entry_deleted`, `entry_too_few_lines`, `entry_unbalanced`, `line_empty`, `line_base_sign`, `line_commodity_mismatch`, `account_archived`, `amount_invalid`, `amount_too_precise`, `amount_out_of_range`, `rate_invalid`, `rate_missing`, `rate_base_conflict`, `date_invalid`, `missing_reference`, `conflict`

### `delete_entry`

Deletes an entry as a tombstone revision; undo brings it back.

- Input: { entry: `DocId` }
- Output: `DocRef`
- Errors: `entry_deleted`, `missing_reference`, `conflict`

### `undo`

Goes one version back for a document. Repeats until the first version.

- Input: { doc: `DocId` }
- Output: `DocRef`
- Errors: `nothing_to_undo`, `account_locked`, `missing_reference`, `conflict`

### `redo`

Brings back what the last undo took away, while nothing was changed after it.

- Input: { doc: `DocId` }
- Output: `DocRef`
- Errors: `nothing_to_redo`, `account_locked`, `missing_reference`, `conflict`

### `history`

Lists every revision of a document in stored order.

- Input: { doc: `DocId` }
- Output: list of `HistoryItem`
- Errors: `missing_reference`

### `system_account`

Finds the account the system opened under a key, such as rounding.

- Input: { key: `string` }
- Output: { doc_id: `DocId` }
- Errors: `missing_reference`

### `account`

Reads an account.

- Input: { account: `DocId` }
- Output: `AccountView`
- Errors: `missing_reference`

### `entry`

Reads an entry.

- Input: { entry: `DocId` }
- Output: `EntryView`
- Errors: `missing_reference`

### `api_version`

The version of this contract.

- Input: `Empty`
- Output: { version: `string` }
- Errors: none of its own

## Shared shapes

- `DocId`: `string`. A UUID in lower case. Opaque: never parse it.
- `RevisionId`: `undefined`. The id of one revision.
- `Amount`: `string`. A decimal number as text, in the scale of its commodity. Never a JSON number.
- `Rate`: `string`. A positive decimal number as text.
- `Date`: `string`. A civil Gregorian date, YYYY-MM-DD, no time zone.
- `AccountKind`: `asset` | `liability` | `equity` | `income` | `expense`
- `Error`: { error: { code: `ErrorCode`, message: `string` } }
- `DocRef`: { doc_id: `DocId`, revision_id: `RevisionId` }
- `SettingsView`: { base_commodity: `DocId`, base_code: `string`, base_scale: `integer` }
- `AccountInput`: { name: `string`, parent?: `DocId` or `null`, kind: `AccountKind`, commodity: `DocId` }
- `AccountView`: { name: `string`, parent: `DocId` or `null`, kind: `AccountKind`, commodity: `DocId`, archived: `boolean`, locked: `boolean`, system_key: `string or null` }
- `LineInput`: { account: `DocId`, amount: `Amount`, rate?: `Rate` or `null`, base?: `Amount` or `null` }
- `EntryInput`: { date: `Date`, memo?: `string or null`, no?: `string or null`, lines: list of `LineInput` }
- `LineView`: { account: `DocId`, commodity: `DocId`, amount: `Amount`, base: `Amount`, rate: `Rate` or `null` }
- `EntryView`: { deleted: `boolean`, date: `Date`, memo: `string or null`, no: `string or null`, lines: list of `LineView` }
- `Restore`: { kind: `undo` | `redo`, from: `RevisionId` }
- `HistoryItem`: { revision_id: `RevisionId`, parent_id: `RevisionId` or `null`, author_id: `DocId`, created_at_ms: `integer`, restore: `Restore` or `null`, head: `boolean`, conflict: `boolean` }
- `Empty`: `{}`
