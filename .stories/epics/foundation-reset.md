# Epic: Foundation reset

**Slug:** foundation-reset
**Status:** in-progress
**Created:** 2026-10-13

## Goal

Re-examine every document and decision from scratch and rewrite the product purpose, future goals, and the backend foundation (technology, methods, boundaries) on solid ground before more features are built. Output: a new vision document, an inventory of existing decisions with keep/change/drop verdicts, and a new set of ADRs. Working mode: the assistant interviews the owner without limit and challenges wrong assumptions critically.

## Scope

- Vision, purpose, users, long-term goals, non-goals
- Backend: data model, storage, write path, rules enforcement, API shape, security and identity, backup and migration, testing strategy
- Review of all docs, ADRs and specs against the new foundation
- Backend technical design document and diagrams

## Out of Scope

- UI and UX redesign (a later epic, after the backend foundation)
- New product features until the foundation is approved
